# J-World Clothes — Affiliate Fashion Hub

A production-ready affiliate clothing & fashion website with a high-speed admin management dashboard.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Admin Dashboard (Manage Products, Images & Links)

**URL:** [http://localhost:5173/admin](http://localhost:5173/admin)

**Passcode:** `jworld2026`

You can also reach it from the footer link **Site Admin**.

### What you can do in Admin
- Paste product images with **Ctrl+V** or paste an image URL
- Add your **affiliate / source links** for each product
- Set title, brand, price, sizes, category, stock status
- Edit, delete, or toggle products in the catalog table
- Export / Import catalog as JSON backup

> The 16 demo products ship with placeholder links (Zara, Nike, etc.) for display only.
> Replace them with your real affiliate links via Admin, or delete and add new products.

## Build

```bash
npm run build
npm run preview
```
